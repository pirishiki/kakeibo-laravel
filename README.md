# 家計簿アプリ

自分のお金の出入りを記録して、「今いくらあるか」「何にいくら使ったか」「いつ、いくら引き落とされるか」がわかる Web アプリ。

プログラミングスクール初級編の最終課題。

## 技術スタック

| 層 | 技術 |
|---|---|
| 画面・サーバー | PHP + Laravel |
| データベース | MySQL |
| インフラ | AWS（EC2・RDS）を Terraform で作る |

くわしくは [要件定義書](要件定義書.md) を参照。
